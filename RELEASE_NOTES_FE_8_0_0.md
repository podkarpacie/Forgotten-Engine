# FE 8.0.0 — Tibia 8.0 Compatibility Foundation

FE 8.0.0 adds the first direct Tibia 8.0 profile to Forgotten Engine. It is intentionally independent of TFS 1.2: the release targets the Tibia 8.0 protocol line itself, while preserving the separate FE 1.2.0 / TFS 1.2 / Tibia 10.98 profile.

The release completes the user-facing rename to **Forgotten Engine**, adds explicit runtime profile selection and profile-specific configuration validation, and keeps all compatibility claims deliberately bounded. It does not claim complete Tibia 8.0 network, gameplay, map, content, or scripting emulation.

See [VERSIONING.md](VERSIONING.md) for exact compatibility mappings and limitations.
